# Plumbing — Grease Interceptors, Fixture Counts, Restroom Requirements

This reference covers California Plumbing Code requirements for grease waste management and minimum plumbing fixture counts in restaurant spaces.

---

## 1. Grease Interceptors (CPC 1014)

### When Required

Required where waste pretreatment is needed: restaurants, cafes, lunch counters, cafeterias, bars, clubs, hotels, hospitals, school kitchens (CPC 1014.1).

### Connection Rules

| Rule | Code Section |
|------|-------------|
| Food waste disposers shall NOT connect to or discharge into a grease interceptor | CPC 1014.1.3 |
| Food waste disposers must connect to a separate trap | CPC 1014.1.3 |
| Dishwashers shall NOT connect to or discharge into a grease interceptor | CPC 1014.1.3 |
| Grease interceptor NOT in food/utensil handling area (unless approved by enforcement agency) | HSC 114201(a) |
| Grease traps must be easily accessible for servicing | HSC 114201(b) |

### Hydromechanical Grease Interceptors (CPC 1014.2)

Sizing: Capacity = 2.5x the certified GPM flow rate (CPC Table 1014.2.1).

### Gravity Grease Interceptors — Sizing by DFU (CPC Table 1014.3.6)

| Drainage Fixture Units (DFU) | Minimum Capacity (gallons) |
|------------------------------|---------------------------|
| 8 | 500 |
| 21 | 750 |
| 35 | 1,000 |
| 90 | 1,250 |
| 172 | 1,500 |
| 216 | 2,000 |
| 307 | 2,500 |
| 342 | 3,000 |
| 428 | 4,000 |
| 576 | 5,000 |
| 720 | 7,500 |
| >720 | 10,000 |

### Location

Must be installed outside the kitchen/food handling area. Must be accessible for cleaning and servicing.

## 2. Fixture Counts for A-2 Occupancy (CPC Table 422.1)

### Water Closets

| Occupant Load | Male | Female |
|---------------|------|--------|
| 1-25 | 1 | 1 |
| 26-50 | 1 | 2 |
| 51-100 | 2 | 3 |
| 101-150 | 2 | 4 |
| 151-200 | 3 | 4 |
| 201-300 | 3 | 6 |
| 301-400 | 4 | 8 |
| Over 400 | Add 1 per 250 males | Add 1 per 125 females |

### Urinals (Male)

| Occupant Load | Count |
|---------------|-------|
| 1-200 | 1 |
| 201-300 | 2 |
| 301-400 | 3 |
| 401-600 | 4 |
| Over 600 | Add 1 per 300 males |

### Lavatories (Handwash Sinks)

| Occupant Load | Male | Female |
|---------------|------|--------|
| 1-150 | 1 | 1 |
| 151-200 | 2 | 2 |
| 201-400 | 3 | 4 |
| Over 400 | Add 1 per 250 males | Add 1 per 200 females |

### Drinking Fountains

| Occupant Load | Count |
|---------------|-------|
| 1-250 | 1 |
| 251-500 | 2 |
| 501-750 | 3 |
| Over 750 | Add 1 per 500 |

### Service Sink

1 service sink or laundry sink required per facility (CPC Table 422.1).

### Calculation Rules (CPC 422.1.1)

| Rule | Detail |
|------|--------|
| Gender split | Calculate at 50% male / 50% female |
| Rounding | Round fractions up |
| Small occupancy exception | Occupant load <=10: one toilet facility for both sexes permitted |

---

## 3. Customer Toilet Access (CPC 422.4.1)

Customer toilet access shall NOT pass through:
- Kitchens
- Food preparation areas
- Storage rooms

---

## 4. Employee Lavatory Temperature (CPC 422.11)

Employee lavatories in food establishments must provide **tempered water: 100-115 deg F**.

---

## 5. Fixture Count Example — Typical Restaurant

**Example**: 2,400 sq ft dining (tables/chairs) + 800 sq ft kitchen

Occupant load:
- Dining: 2,400 / 15 = 160 occupants
- Kitchen: 800 / 200 = 4 occupants
- **Total: 164 occupants** (82 male / 82 female)

Minimum fixtures:
| Fixture | Male | Female |
|---------|------|--------|
| Water closets | 2 | 4 |
| Urinals | 1 | — |
| Lavatories | 1 | 1 |
| Drinking fountains | 1 (shared) | |
| Service sink | 1 (shared) | |
