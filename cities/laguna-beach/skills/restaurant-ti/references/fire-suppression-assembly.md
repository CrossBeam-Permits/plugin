# Fire — Hood Suppression and Assembly Fire Requirements

This reference covers fire code requirements for kitchen hood suppression systems and assembly occupancy fire protection in restaurant TI projects.

---

## 1. Kitchen Hood Fire Suppression (CMC 513, CFC 904.14)

### System Type

| Requirement | Code Section |
|-------------|-------------|
| Must comply with UL 300 (wet chemical systems) | CMC 513 |
| ALL existing dry and wet chemical systems must comply with UL 300 | CMC 513 |
| Carbon dioxide extinguishers prohibited | CMC 513 |

### Actuation

| Requirement | Code Section |
|-------------|-------------|
| Must have both automatic AND manual actuation | CMC 513 |
| Upon actuation, the fuel or electrical power supply to the cooking equipment automatically shuts down; reset is manual | CFC 904.14.2 |
| Exhaust fan continues to operate after activation unless shutdown is required by a listed ventilation-system component or the extinguishing-system design | CMC 511.2.3 |
| Fan interlock: exhaust fan activates when any heat-producing cooking appliance under the hood turns on | CMC 511.2.3 |

### Nozzle Placement

| Requirement | Code Section |
|-------------|-------------|
| Nozzles located/installed per manufacturer's listed manual | NFPA 17A 6.1 |
| Nozzles must have caps, covers, or protective devices | NFPA 17A 6.1.5 |
| Field-adjusted nozzles or moved pipe/nozzles require evaluation by approved contractor | NFPA 17A |

### Manual Pull Stations

| Parameter | Value | Code Section |
|-----------|-------|-------------|
| Height above finished floor | 42-48 inches | NFPA 17A |
| Distance from means of egress from kitchen | Within 10 feet | NFPA 17A |
| Maximum distance from hood edge | 25 feet | NFPA 17A |
| Multiple systems | Permanent sign identifying which system each actuator controls | NFPA 17A |

### Portable Extinguishers

| Requirement | Code Section |
|-------------|-------------|
| Class K-rated extinguisher within 30 ft of cooking equipment | CFC 906 |
| Placard near each extinguisher: "FIRE PROTECTION SYSTEM — ACTIVATE PRIOR TO USING FIRE EXTINGUISHER" | NFPA 17A |

### System Monitoring

| Requirement | Code Section |
|-------------|-------------|
| Where building fire alarm/monitoring exists: hood suppression must be monitored | CFC 904.3.5 |
| Kitchen hood suppression must transmit alarm to central supervising station AND activate all notification devices | CFC 904.3.5 |

### Baffle Plates

Where the grease removal device is less than 18 inches from the appliance flue outlet or heat source, the required protection may be a steel or stainless steel baffle plate between the heat source and the grease removal device (CMC 509.2.2 and 509.2.2.1).

## 2. Sprinkler Requirements for A-2 (CBC 903.2.1.2)

Automatic sprinkler system required for Group A-2 when ANY of:

| Trigger | Threshold | Code Section |
|---------|-----------|-------------|
| Fire area size | >5,000 sq ft | CBC 903.2.1.2 |
| Occupant load | >=100 persons | CBC 903.2.1.2 |
| Floor level | Not on level of exit discharge | CBC 903.2.1.2 |
| Multiple fire areas | Structure >5,000 sq ft with multiple A-2 fire areas without 4-hour separation | CBC 903.2.1.2 |

---

## 3. Fire Alarm for Group A (CBC 907.2.1)

| Trigger | Requirement | Code Section |
|---------|-------------|-------------|
| Assembly occupant load >=300 | Manual fire alarm system required | CBC 907.2.1 |
| Assembly occupant load >100 above/below level of exit discharge | Manual fire alarm system required | CBC 907.2.1 |
| **Exception** | Manual pull stations not required if sprinklered throughout with notification on waterflow | CBC 907.2.1 |
| Assembly occupant load >=1,000 | Emergency voice/alarm communication system | CBC 907.2.1 |

## 4. Maintenance Requirements

### Hood Suppression Service

| Requirement | Frequency | Code Section |
|-------------|-----------|-------------|
| System service/inspection | Every 6 months (or after activation) | NFPA 17A A7.3 |
| Fusible link replacement | Annually | CFC 904.14.5.3 |

### Hood/Duct Cleaning Frequency (CMC Table 609.3.3)

| Cooking Type | Cleaning Frequency |
|-------------|-------------------|
| 24-hour cooking / charbroiling / wok | Every 3 months |
| Moderate-volume (religious facilities, seasonal) | Every 6 months |
| Solid fuel burning appliances | Every 1 month |
| All other | Every 6 months |

### Solid Fuel Equipment (Wood-Fired Ovens, Charcoal Grills)

| Requirement | Code Section |
|-------------|-------------|
| No combustible/flammable liquids for ignition | CFC |
| Ash removed minimum once daily | CFC |
| Ash sprayed with water before removal | CFC |
| Ash in separate heavy metal container, placed outside building | CFC |
| Metal-fabricated solid fuel appliances must be listed for application | CFC |

## 5. Assembly Egress Fire Requirements

### Number of Exits (CBC Table 1006.2.1)

| Occupant Load | Minimum Exits |
|---------------|--------------|
| 1-49 | 1 |
| 50-500 | 2 |
| 501-1,000 | 3 |
| >1,000 | 4 |

### Exit Travel Distance (Group A)

| Sprinklered | Unsprinklered |
|-------------|---------------|
| 250 feet | 200 feet |

### Occupant Load Posting

Must be posted when 50+ occupants in any assembly room (CBC 1004.9).
