# AB 671 — Restaurant TI Fast-Track Pathways

AB 671 (Wicks, Chapter 470, Statutes of 2025), effective January 1, 2026, creates a fast-track permitting pathway for restaurant tenant improvements. This reference covers both the QPC (Qualified Professional Certifier) pathway and the standard pathway with new timelines.

---

## 1. Eligibility — Four Gates

A project qualifies for AB 671 fast-track if ALL four conditions are met:

| Gate | Requirement | Code Section |
|------|-------------|-------------|
| 1 | **Interior changes to existing building** (tenant improvement, not new construction) | Gov. Code 66345.1(c) |
| 2 | **Retail food establishment** that prepares, serves, and vends food directly to consumers | Gov. Code 66345.1(b) |
| 3 | **NOT fast food** per Labor Code 1474 (60+ national chain locations, limited-service) | Gov. Code 66345.1(b) |
| 4 | **NOT subject to** CRFC plan review requirements under HSC 114380 Article 1 for the building permit pathway — health side has its own parallel timeline | Gov. Code 66345.2(d)(3) |

**Important**: Gate 4 means the QPC pathway applies to the BUILDING permit side. The HEALTH permit side (CRFC/enforcement agency) has its own parallel 20-business-day deemed-approval timeline under HSC 114380(f), but the QPC certification does not cover health review.

---

## 2. QPC Pathway (Gov. Code 66345.2)

### QPC Qualifications (Gov. Code 66345.1(a))

| Requirement | Detail |
|-------------|--------|
| License | California licensed architect (BPC Ch. 3, section 5500+) OR professional engineer (BPC Ch. 7, section 6700+) |
| Experience | Minimum 5 years in commercial building design or plan review |
| Insurance | Professional liability insurance not less than $2,000,000 per occurrence |

### QPC Submission Requirements

| Document | Requirement | Code Section |
|----------|-------------|-------------|
| QPC Affidavit | Under penalty of perjury: plans comply with all applicable building, health, and safety codes (CBSC + local standards) | Gov. Code 66345.2(b)(1)(A) |
| Restaurant Affidavit | Under penalty of perjury (by QPC or applicant): restaurant meets definition in 66345.1(b) | Gov. Code 66345.2(b)(1)(B) |

### What QPC Certification Does NOT Exempt

| Exemption | Code Section |
|-----------|-------------|
| Does NOT exempt from mandatory construction inspections (fire, health, structural) | Gov. Code 66345.2(d)(1) |
| Does NOT limit local health department authority under CRFC | Gov. Code 66345.2(d)(2) |
| Does NOT apply to TIs subject to CRFC plan review (health side has own timeline) | Gov. Code 66345.2(d)(3) |

---

## 3. Timelines — Both Pathways

### Building Permit Side (Gov. Code 66345.2)

| Phase | Timeline | Code Section |
|-------|----------|-------------|
| Initial review of complete application | **20 business days** | Gov. Code 66345.2(b)(2) |
| If no decision within 20 business days | **Deemed approved** (fees and docs must be submitted) | Gov. Code 66345.2(b)(3) |
| Resubmission after denial | **10 business days** | Gov. Code 66345.2(b)(4) |
| Resubmission scope | **Limited to deficiencies identified in initial denial** (no new issues) | Gov. Code 66345.2(b)(4) |

### Health/CRFC Side (HSC 114380(f))

| Phase | Timeline | Code Section |
|-------|----------|-------------|
| Initial review by enforcement agency | **20 business days** | HSC 114380(f)(1) |
| If no decision within 20 business days | **Deemed approved** (fees and docs must be submitted) | HSC 114380(f)(1) |
| Resubmission after denial | **10 business days** | HSC 114380(f)(2) |
| Resubmission scope | **Limited to deficiencies identified in initial denial** | HSC 114380(f)(2) |

### General Plan Review (Non-AB 671, HSC 114380(e))

| Phase | Timeline | Code Section |
|-------|----------|-------------|
| General food facility plan review | 20 working days to approve or reject | HSC 114380(e) |
| If no decision | Deemed approved | HSC 114380(e) |
| Building dept restriction | Shall NOT issue building permit until enforcement agency approves | HSC 114380(e) |

## 4. Audit Requirements (Gov. Code 66345.2(c))

QPC-certified submissions are subject to random post-permit audit:

| Parameter | Value | Code Section |
|-----------|-------|-------------|
| Audit rate | Minimum 20% of all weekly QPC submissions | Gov. Code 66345.2(c)(1) |
| Audit initiation deadline | Within 5 business days following permit issuance | Gov. Code 66345.2(c)(2) |
| Audit scope | Review submitted plans for compliance with all applicable codes (CBSC + local) | Gov. Code 66345.2(c)(2) |
| Material noncompliance notice | Within 10 business days of audit initiation | Gov. Code 66345.2(c)(3) |

**Note**: "Material noncompliance" is not defined in the statute. This is a judgment call for the local building department.

---

## 5. Liability Framework (Gov. Code 66345.4)

| Party | Liability | Code Section |
|-------|-----------|-------------|
| QPC | Liable for damages arising from negligent plan review | Gov. Code 66345.4(a) |
| Applicant | Must indemnify the local agency from property damage or personal injury | Gov. Code 66345.4(b) |
| Public entity/employee | Immune from injury caused by acts/omissions relating to permit issuance/denial | Gov. Code 66345.4(c) |

---

## 6. Local Authority to Customize (Gov. Code 66345.2(f))

Cities and counties may adopt by ordinance:

| Additional Requirement | Code Section |
|------------------------|-------------|
| QPC registration requirement prior to certifying plans | Gov. Code 66345.2(f)(1) |
| Training requirements prior to certifying plans | Gov. Code 66345.2(f)(2) |
| Fees not exceeding reasonable cost of implementation | Gov. Code 66345.2(f)(3) |
| Penalties including decertification for willful noncompliance or 2+ noncompliant certifications | Gov. Code 66345.2(f)(4) |

---

## 7. Disciplinary Consequences

| Action | Consequence | Code Section |
|--------|-------------|-------------|
| False statements in QPC architect certification | Grounds for discipline by California Architects Board | BPC 5586.5 |
| False statements in QPC engineer certification | Grounds for discipline by Board for Professional Engineers | BPC 6775(g) |

---

## 8. Statewide Preemption

Legislature explicitly finds this is a matter of statewide concern, not a municipal affair. Applies to all cities including charter cities (Section 5 of the act).

---

## 9. Permit Fees

AB 671 does not prohibit local building departments from charging permit fees for QPC applications (Gov. Code 66345.3).

## Pre-Check Pathway Determination

Help the applicant determine which pathway applies:

```
Is this a tenant improvement (interior change to existing building)?
├── NO → AB 671 does not apply. Standard permit process.
└── YES
    └── Is this a restaurant (prepares/serves food directly to consumers)?
        ├── NO → AB 671 does not apply.
        └── YES
            └── Is this a fast-food restaurant (60+ national locations, limited-service)?
                ├── YES → AB 671 does not apply. Standard permit process.
                └── NO → AB 671 APPLIES
                    └── Does the applicant have a QPC?
                        ├── YES → QPC Pathway
                        │   • Submit affidavits + plans
                        │   • 20 business day review
                        │   • Deemed approved if no decision
                        │   • Subject to 20% random audit
                        └── NO → Standard AB 671 Pathway
                            • Same 20 business day timeline
                            • Same deemed-approval mechanism
                            • No QPC audit
                            • No QPC liability shift
```
