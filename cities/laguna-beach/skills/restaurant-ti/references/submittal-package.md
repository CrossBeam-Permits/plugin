## Required Sheet Sets

Typical full-scope restaurant TI submittal — **5–8 sheet sets**:

| Set | Contents |
|-----|----------|
| **Architectural (incl. T-24 envelope)** | Floor plans, RCP, partition schedule, finish schedule, ADA path of travel, occupant load, exit analysis, code summary |
| **Mechanical** | HVAC layout, Type I hood + grease duct, exhaust calcs, makeup air, T-24 mechanical compliance forms, RTU schedules with sound data |
| **Plumbing** | Sinks (hand, prep, 3-comp warewash, jan sink), grease interceptor, indirect waste, water heater, gas piping, T-24 hot water compliance |
| **Electrical** | Power, lighting, panel schedule, T-24 LPD compliance forms, EV-ready stub-outs if applicable |
| **Fire sprinkler** | Deferred — NFPA 13 design, hydraulic calcs, hydrant flow test ≤6 mo |
| **Fire alarm** | Deferred — NFPA 72, 24-hr UL central station monitoring |
| **Signage** | If exterior — face area, illumination, materials, character per Ch. 25.54 |
| **Structural** | If structural alterations or new openings — calcs, details, special inspections |

**Design Review exhibits** (if exterior work) — separate from building set:

- Elevations with materials and colors annotated
- Materials board (physical samples)
- Color samples
- Lighting cut sheets
- Awning details and fabric samples
- Sign details
- Outdoor furniture cut sheets (if outdoor dining)

## OCHCA Submittal (Parallel)

OCHCA Environmental Health reviews every food facility in Orange County, including Laguna Beach. This submittal runs in parallel with the city tracks.

| Item | Detail |
|------|--------|
| Submittal address | 1241 E Dyer Rd Suite 120, Santa Ana, CA 92705 |
| Portal | myhealthdepartment.com/orange-county |
| Plan sets | 3 sets of plans (architectural, plumbing, mechanical relevant to food areas) |
| Application | EH Cover Sheet (download from plan check resources) + menu + equipment specs |
| Plan check fee | Per OCHCA fee schedule |
| Timeline | ~20 business days initial; 10 business days expedited if requested |
| Reviews / inspections included | 3 plan reviews + 3 construction inspections in service fee |
| Pre-submittal consultation | outlook.office365.com/book/PlanCheck1@ocgov.onmicrosoft.com |
| Approval validity | One year from date of approval |
| 80% inspection | OCHCA recommends preliminary inspection at ~80% construction completion |
| Contact | plancheck@ochca.com / (714) 433-6074 |

**Building permit issuance is conditioned on OCHCA plan-approval letter.** Plan OCHCA submittal from day 1 — it is the most common late-stage blocker on Laguna restaurant TIs.

## Public Works Submittal (only if ROW work)

Required only when the scope includes any work in the public right-of-way (sidewalk dining, curb cut, utility connection in ROW, driveway alteration, street tree work).

| Item | Detail |
|------|--------|
| Application | Public Works encroachment permit application |
| Plan set | Site plan + section through ROW + insurance certificate |
| Insurance | City-required liability coverage |
| Indemnity | Standard hold-harmless |
| Annual renewal | Some ROW uses (sidewalk café) require annual renewal |

## Pre-Application Checklist

Before formal submittal, verify:

1. Zoning permits restaurant use in the parcel's zone (check zoning map and Title 25 use tables)
2. Coastal Zone status — assume yes; CDP application planned
3. CUP triggers identified (alcohol, entertainment, late hours, drive-thru, outdoor dining, intensification)
4. Design Review path identified (Admin DR vs PC, or N/A for interior-only)
5. Parking demand calculated, intensification analysis run, in-lieu fee acknowledged if shortfall
6. Sprinkler retrofit analysis run for both Group A (valuation) and Group R (scope) triggers
7. OCHCA pre-submittal consultation booked
8. LBFD coordination on Type I hood, suppression, sprinkler, alarm
9. Construction hours note on Sheet G-1
10. Code cycle = 2025 California Building Standards Code

## Output Findings

- **PASS** — All required sets present; entitlement applications filed; OCHCA submittal initiated; deferred submittals identified; pre-application checklist complete.
- **FAIL** — Required set missing (e.g., no mech plan with hood, no plumbing for grease interceptor, no T-24 forms); wet stamp missing; 2022 code cycle cited; OCHCA submittal not started.
- **FLAG** — Sheet count under typical minimum but scope unclear; staff to confirm whether deferred submittals are scheduled.
- **N/A** — Change-of-ownership only with zero construction work (operational review only via OCHCA / business license).
