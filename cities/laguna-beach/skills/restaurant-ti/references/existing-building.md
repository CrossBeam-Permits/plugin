# Existing Building Code — Alterations and Change of Occupancy

This reference covers the California Existing Building Code (Title 24 Part 10) requirements that determine how much of the current building code applies to a restaurant TI project. This is critical because restaurant TIs are, by definition, alterations to existing buildings.

---

## 1. Classification of Work (CEBC Chapter 6)

### Alteration Levels

| Level | Definition | Threshold | Code Section |
|-------|-----------|-----------|-------------|
| **Level 1** | Removal, replacement, or covering of existing materials with same-purpose materials | Cosmetic/like-for-like changes | CEBC 602 |
| **Level 2** | Addition/elimination of doors/windows, reconfiguration of systems, installation of equipment | Work area <=50% of building area | CEBC 603 |
| **Level 3** | Same as Level 2 but larger scope | Work area >50% of building area | CEBC 604 |
| **Change of Occupancy** | Change in the type of use or occupancy classification | Applies per Chapter 10 | CEBC 605 |

**Key for restaurant TI**: Most restaurant TIs in an existing shell are Level 2 (work area <=50%). If the previous use was NOT a restaurant (e.g., retail, office), it is ALSO a change of occupancy, which triggers Chapter 10 requirements on top of the alteration level.

---

## 2. Level 1 Alterations (CEBC Chapter 7)

| Requirement | Code Section |
|-------------|-------------|
| Building shall not be made less safe than existing condition | CEBC 701.2 |
| New materials must comply with current CBC | CEBC 702.7 |
| Fire protection systems must be maintained | CEBC 703.1 |

---

## 3. Level 2 Alterations (CEBC Chapter 8)

In addition to Level 1 requirements:

| Requirement | Code Section |
|-------------|-------------|
| Vertical openings must be enclosed with 1-hour rated assemblies | CEBC 802.2.1 |
| Exception: sprinklered buildings may have reduced requirements | CEBC 802.2.1 exceptions |
| Interior finish in exits and corridors must comply with current CBC | CEBC 802.4 |
| Sprinklers per CBC Section 903 if triggered | CEBC 803.2 |
| Fire alarm per CFC Section 907 if triggered | CEBC 803.4 |

---

## 4. Level 3 Alterations (CEBC Chapter 9)

All Level 1 and Level 2 requirements apply, plus:

| Requirement | Code Section |
|-------------|-------------|
| Egress lighting and exit signs from highest work area to exit discharge per CBC | CEBC 905.2-905.3 |
| Sprinklers per CBC for new construction | CEBC 904.1 |
| Fire alarm per CBC for new construction | CEBC 904.2 |

---

## 5. Change of Occupancy (CEBC Chapter 10)

### When Change of Occupancy Applies

Any time the occupancy classification changes. For restaurant TI, the most common trigger is converting from:
- Group B (office) → Group A-2 (restaurant)
- Group M (retail/mercantile) → Group A-2 (restaurant)
- Group F-1 (factory) → Group A-2 (restaurant)
- Group S-1 (storage) → Group A-2 (restaurant)

### Certificate of Occupancy

Certificate of occupancy required; cannot change without approval (CEBC 1001.2).

### Hazard Category Assessment

The code uses hazard categories to determine if the new use is MORE hazardous than the old use.

**Means of Egress Hazard Categories (Table 1011.5)**:

| Occupancy Group | Hazard Category |
|----------------|----------------|
| A (Assembly) | 3 (higher hazard) |
| B (Business) | 4 (lower hazard) |
| F-1 (Factory) | 4 |
| M (Mercantile) | 4 |
| S-1 (Storage) | 4 |

**Changing from B, M, F-1, or S-1 → A-2 = change to HIGHER hazard = full Chapter 10 CBC egress compliance required.**

**Heights and Areas Hazard Categories (Table 1011.6)**:

| Occupancy Group | Hazard Category |
|----------------|----------------|
| A-2 | 2 (higher hazard) |
| B | 4 (lower hazard) |

### Specific Change of Occupancy Requirements

| Requirement | Trigger | Code Section |
|-------------|---------|-------------|
| Fire protection per current CBC Chapter 9 | When there is a different threshold between old and new occupancy | CEBC 1004.1 |
| Sprinkler installation | Required within area of change if CBC Chapter 9 requires it for new A-2 occupancy | CEBC 1011.2.1 |
| Fire alarm | Required if CBC Chapter 9 requires it for new A-2 occupancy | CEBC 1011.2.2 |
| Egress capacity | Must meet current CBC for new A-2 occupancy | CEBC 1011.5.3 |
| Kitchen exhaust or increased ventilation | Must comply with current CMC | CEBC 1008.1 |
| Increased plumbing fixtures | Required only when occupant load increases by >20% | CEBC 1009.1 |
| Sanitary waste lines above food areas | All existing lines must be panned/protected | CEBC 1009.2 |
| Grease interceptor | Required if new occupancy produces grease/oil waste | CEBC 1009.3 |

## 6. Common Restaurant TI Scenarios

### Scenario A: New Restaurant in Former Retail Space (M → A-2)

This is a **change of occupancy** (higher hazard). Triggers:
- Full egress compliance for A-2 occupant load
- Sprinklers if >5,000 sq ft or >=100 occupants
- Fire alarm if >=300 occupants
- New kitchen exhaust per CMC
- New plumbing fixtures per CPC Table 422.1 for A-2
- Grease interceptor required
- Sanitary waste line protection above food areas
- Accessibility compliance per CBC 11B

### Scenario B: Restaurant Remodel (A-2 → A-2, Same Occupancy)

This is an **alteration** (Level 1, 2, or 3 depending on scope). No change of occupancy.
- Level 1: cosmetic (new finishes, equipment swap) — maintain existing safety
- Level 2: layout change, new doors/windows — vertical openings, interior finish, maintain fire protection
- Level 3: major remodel >50% of building — full egress lighting, sprinkler/alarm per new construction

### Scenario C: Restaurant in Former Office (B → A-2)

Same as Scenario A — change of occupancy to higher hazard. All Chapter 10 requirements apply.

### Scenario D: Expanding into Adjacent Space (Same A-2)

If the expansion increases the fire area or occupant load, check:
- Does total fire area now exceed 5,000 sq ft? → Sprinklers required
- Does occupant load now exceed 100? → Sprinklers required
- Does occupant load now exceed 300? → Fire alarm required
- Are fixture counts still adequate for new occupant load?
