# Laguna Beach — document / forms index

Every City document link is `https://www.lagunabeachcity.net/home/showpublisheddocument/{id}/{ticks}`.
The **ticks** segment is a version stamp: if a document is republished, the ticks
change while the id stays the same. That is our free PDF change-detection signal —
the City source document (not included in this plugin) records `{id: {ticks, title, url}}`
for all **138** document links found across the Community Development section.

**When giving a resident a link, give the id-and-ticks URL from this file.** A
bare the `id` skills in this plugin (no ticks) also resolves but won't tell you
whether the document has been revised.

All entries below are `as of 2026-08-09` (the extraction date); the page each was
found on carries its own `lastmod` in `baseline.json`.

## CEQA document set

of Exemption, Determination, Intent, Availability, Preparation, and Completion,
Draft and Final Initial Studies / Negative Declarations, appendices, and

recorded in `baseline.json` by id and ticks for change detection, but they are
