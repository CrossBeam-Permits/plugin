# Laguna Beach — Commercial TI Submittal Package

**Authority:** City of Laguna Beach Community Development Department — Building Division, Planning Division, Public Works. LBFD Fire Prevention Division. City counter policies and the Building Plan Check FAQ.

**No dedicated "commercial TI checklist" handout exists.** Commercial TI is handled through the general building-application + planning-application + design-review-application + (when applicable) coastal-development-permit-application stack. The governing handout is `building-plan-check-submittal-requirements.pdf` (doc ID 5103, current 2025-cycle version) — verbatim source for plan-set counts, fee deposits, and cover-sheet content. The pre-permit checklist `building-submittal-requirements-prior-to-permit.pdf` (doc ID 10228) covers post-approval-pre-permit items.

**The text of both PDFs is in `crossbeam.source_documents`** (Section 11 has the locators; `node scripts/source-corpus.mjs get laguna-beach --url <url>`).

## 1. Submittal Sequence — Required Before Building Plan Check

Laguna runs a **sequenced multi-department intake**. Building Division does NOT accept a commercial TI submittal until Planning Division and Public Works have signed off.

| Step | Department | Scope | Output |
|------|-----------|-------|--------|
| **1. Planning Division — Zoning Plan Check** | Planning | Setbacks, height, parking, open space, lot coverage, use, specific-plan compliance, sign program compliance | Zoning clearance / corrections |
| **2. Planning Commission — Design Review** (only if a current §25.05.040(B)(1) category matches; concurrent with CDP if applicable) | Planning Commission | DR per §25.05.040; CDP per Ch. 25.07; Fire Department or Building Division review before DR action for new construction and major remodels (§25.05.040(C)(4)). Interior-only work and a use change alone take Zone Clearance instead (§25.05.040(B)(2)(d); §25.05.045(B)(2)). A CDP with no other discretionary permit goes to a Director hearing (§25.07.012(D)(1)) | DR approval + CDP (where applicable) |
| **3. Public Works** | Public Works | Encroachment, right-of-way, sidewalk, ADA path-of-travel in ROW, storm drainage | PW clearance / encroachment permit |
| **4. Caltrans** (if applicable) | State (Caltrans District 12) | Frontage work on PCH (Hwy 1) or Laguna Canyon Rd (Hwy 133) | Caltrans encroachment permit |
| **5. Building Plan Check** | Building Division | Full code review (CBC / CMC / CPC / CEC / Energy / CALGreen) + LBFD building-plan-check review | Building permit |
| **6. LBFD Building Plan Check** | LBFD Fire Prevention | Fire-protection systems, fire alarm, sprinklers, FDC, hydrant flow, HMMP/HMIS | LBFD approval |

When both apply, Planning Commission DR + CDP run concurrently and produce a single approval action with two appeal windows (14-day City Council DR appeal; 10-working-day CCC appeal for appealable CDPs).

## 2. Plan Sets — per doc 5103 (verbatim)

The Building Plan Check handout (doc 5103, current 2025-cycle) classifies commercial TI in one of two buckets:

| Scope | Plan-set count | Distribution |
|---|---|---|
| **Interior renovation / TI < 500 sf added** | **2 complete sets** at 24"×36" | Building + one additional reviewing dept |
| **Larger TI (≥ 500 sf added) or any new commercial structure** | **4 complete sets** at 24"×36" | Building, Planning/Zoning, Fire Department, Water Quality |

**Supporting documents:** 2 sets of structural calculations; 2 sets of geotech soils report when required (with $5,000 peer-review deposit per the soils handout); 2 sets of energy calculations.

**Fire sprinkler plans (deferred submittal):** 3 copies for commercial (vs 2 for residential) per doc 5103.

**Wet stamp:** First sheet wet-stamped and signed by California-licensed architect or engineer of record. Plans must be legible and capable of digital scanning.

**Plan scales (doc 5103):** site plan/plot plan typically **1/8"**; floor plan, elevations, sections typically **1/4"**. Other scales require prior written approval from Building Official or Zoning Administrator. **11"x17"** permitted for minor projects only with prior written approval.

For larger or more complex commercial TIs (e.g., multi-story, change-of-occupancy, structural alterations), additional sets may be requested by Building Division.

### Commercial food operations — add-ons (doc 5103)

Per doc 5103 "Additional requirements for Commercial food operations":

- **Health Department plans** — 2 sets of OCHCA-approved plans (delivered to OCHCA separately; submit Health-approved set to city as part of building submittal).
- **Grease Interceptor Plan** — 2 sets for Water Quality Department approval.

(These supplement the standard sheet sets above.)

### Cover-sheet code-edition statement (doc 5103)

Title sheet MUST contain a statement that this project complies with:
- 2025 California Building Code (CBC)
- 2025 California Residential Code (CRC)
- 2025 California Mechanical Code (CMC)
- 2025 California Plumbing Code (CPC)
- 2025 California Electrical Code (CEC)
- 2025 California Green Building Standards Code (CGBS)
- 2025 California Energy Efficiency Standards (CEES)
- City of Laguna Beach Regulations and Ordinances

Missing or stale (e.g., 2022-cycle) code edition statement → FAIL at intake.

## 4. Cover Sheet Requirements

The cover sheet of the architectural set must include:

- Project address, APN, applicant/owner/architect contacts
- Occupancy classification (current + proposed)
- Construction type
- Building data: floor area (existing + altered + total), occupant load, stories, building height
- Code references: **2025 California Building Standards Code (effective 2026-01-01)** — CBC, CMC, CPC, CEC, Energy Code, CALGreen, CFC, CWUIC
- Local code adoption note: LBMC Title 14 (Building Code amendments), Title 15 (Fire Code amendments)
- Climatic / geographic design criteria: seismic design category, wind speed, Title 24 climate zone and VHFHSZ status, all per `../../city-reference/SKILL.md` §"Climatic and Geographic Design Criteria"
- Sprinkler note: "AUTOMATIC FIRE SPRINKLER SYSTEM REQUIRED" with §14.50.104 citation if applicable
- Sheet index

## 5. Site/Plot Plan Requirements

- North arrow
- All structures (existing + proposed) with dimensions and setbacks
- Property lines
- Easements
- Adjacent right-of-way (curb, gutter, sidewalk, planter strip)
- Parking spaces (dimensioned), aisles, drive approaches, accessible route
- Trash enclosure location and screening
- Mechanical equipment locations (rooftop + ground-mounted) with screening
- Defensible space zones (if in VHFHSZ)
- Distance to property lines and (if applicable) bluff edge

## 6. Discipline-Specific Sheet Requirements

| Discipline | Key sheets |
|-----------|-----------|
| **Architectural** | Cover, site, floor plans (demo + proposed), reflected ceiling, roof plan, elevations, building sections, wall sections, door/window/finish schedules, ADA details |
| **Structural** | Foundation plan, framing plans, structural details, lateral analysis (if applicable), structural calcs in supporting set |
| **Mechanical** | HVAC equipment schedule, ductwork plans, kitchen hood plans (if restaurant), fire damper details, makeup air, energy compliance |
| **Electrical** | Power plan, lighting plan, panel schedules, single-line diagram, Title 24 lighting compliance forms, life-safety circuiting |
| **Plumbing** | Water and waste plans, fixture counts, grease interceptor (if applicable), gas piping, point-of-connection details |
| **Energy (Title 24 Part 6)** | Compliance forms (NRCC for nonresidential), envelope + HVAC + lighting compliance documentation |
| **CALGreen (Title 24 Part 11)** | Construction Waste Management Plan, water-conservation compliance, indoor air quality, commissioning (if applicable) |

## 7. Turnaround Estimates

| Phase | Timeline |
|-------|----------|
| **Zoning Plan Check** | ~30 days (per CD FAQ) |
| **Design Review (Planning Commission)** | Hearing schedule + required notice/posting/staking; typical 6–12 weeks first-hearing-to-final-decision if continuances are avoided; 14-day appeal window |
| **CDP (de minimis waiver)** | ~10 working days |
| **CDP (Administrative)** | 15 working days unless hearing requested |
| **CDP (Appealable, hearing)** | Concurrent with DR; +10 working-day CCC appeal window after final action |
| **Public Works** | Typically concurrent with Planning |
| **Building Plan Check (full)** | 3–6 weeks first round + resubmittal cycles |
| **LBFD Plan Check** | Concurrent with Building Plan Check |
| **OTC (commercial signs without structural alterations only — the city reference OTC item 11)** | Same day; hours in `../../city-reference/SKILL.md` |
| **Aggregate (typical commercial TI with exterior changes in Coastal Zone)** | **4–6 months** from submittal to permit issuance |
| **Aggregate (interior-only TI, non-historic, no DR/CDP)** | **4–8 weeks** |

## 8. Fees Notable

- Set by City Council resolution; not codified line-item in LBMC.
- Building permit fee per ICC Building Valuation Data (with City resolution adjustments).
- Plan check fees per Building, Planning, Public Works, and LBFD schedules.
- **Coastal Development Permit fee separate** from building permit and DR fee.
- **Heritage Committee review fee separate** when triggered.
- **Reinspection fees** per §14.50.026 (CBC §109.7 amendment).
- Caltrans encroachment permit fee is per state schedule (separate from city fees).
