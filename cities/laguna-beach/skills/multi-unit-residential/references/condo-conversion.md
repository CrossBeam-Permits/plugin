# Laguna Beach Condominium Conversion (Ch. 25.47)

Use when an existing apartment building is being converted to condominium or stock cooperative tenure — whether or not physical alterations accompany the conversion. This is the **second most likely multi-unit residential path** in Laguna Beach (after ADU additions to multi-family lots).

## The Critical Citation: §25.07.008(A)(2)(c)

> **Condominium and stock cooperative conversions are NEVER exempt from the Coastal Development Permit requirement under Ch. 25.07.008.**

This is a deliberately narrow carve-out. §25.07.008 generally exempts "improvements to existing structures" from CDP requirements in most cases, but §25.07.008(A)(2)(c) specifically excludes condominium / stock cooperative conversions from that exemption. **Every condo conversion in the Coastal Zone needs a CDP.** Period.

## When This Applies

| Scenario | Conversion review? | CDP required? |
|----------|-------------------|---------------|
| Existing apartments converted to condos with no physical work | YES (Ch. 25.47) | **YES** (§25.07.008(A)(2)(c)) |
| Existing apartments converted to condos with interior reconfiguration | YES (Ch. 25.47) | **YES** |
| Existing apartments converted to condos with exterior remodel | YES (Ch. 25.47) | **YES** + DRB |
| Existing condos being re-subdivided (lot-line / unit-line adjustment) | YES (Ch. 25.47) | **YES** |
| New ground-up condominium construction (already condo from day 1) | NO (this is ground-up R-3) | YES, but not via §25.07.008(A)(2)(c) — via §25.07.004 |

## Ch. 25.47 Conversion Process Elements

| Element | Requirement |
|---------|-------------|
| **Tenant noticing** | Required well in advance of conversion approval. Existing tenants get notice of intent to convert + first right of refusal to purchase their unit. Confirm exact noticing window in Ch. 25.47 at scrape time. |
| **Tentative subdivision map** | Required (Subdivision Map Act overlay) — condominium creates new fee parcels. |
| **Parking compliance** | Conversion must satisfy CURRENT multi-family parking standards (Ch. 25.52). Many older Laguna apartments are deficient by current ratios — confirm or seek waiver/density-bonus parking. |
| **Design / habitability compliance** | Building must meet current habitability standards or get a deficiency waiver. Conversion is a frequent trigger for sprinkler retrofit under Title 15 §1103.5.4 if alteration scope crosses the 50% / 50% / +1 story trigger. |
| **CDP** | **Always required** per §25.07.008(A)(2)(c). |
| **DRB** | Required if exterior modifications proposed; advisory review may apply to tenure-only conversions in some cases. |

## Sprinkler Retrofit Interaction

Most condo conversions need review under both Title 15 §1103.5.4 and LBMC §14.50.104/CBC
§903.6. The former tests physical scope; the latter expressly covers CBC-track Group R work
through its 50%-valuation and Building Official substantial-renovation clauses. Run both before
assuming the existing-building sprinkler stack is grandfathered.

If retrofit is triggered, sprinkler design is **NFPA 13R per state CBC §903.3.1.2** (Laguna does not override 13R for multi-family).

## Submittal Package Specific to Conversion

- Existing-conditions survey + tenant roster (for noticing).
- Tentative subdivision map (Subdivision Map Act).
- CDP application (always; §25.07.008(A)(2)(c)).
- Parking compliance exhibit (current Ch. 25.52 ratios; many older buildings are deficient).
- Habitability / code-compliance report (electrical service capacity per unit, plumbing fixture compliance, smoke/CO alarms, dwelling-unit separation rating per CBC 708.3 = 1-hr fire partition + STC 50 / IIC 50).
- Sprinkler retrofit plans if Title 15 §1103.5.4 triggered.
- DRB submittal if exterior modifications.

## Common FAIL / FLAG Patterns

| Pattern | Severity | Citation |
|---------|----------|----------|
| Applicant claims "CDP exempt — no physical work" | **FAIL** | §25.07.008(A)(2)(c) — condo conversions are NEVER exempt |
| Parking deficient under current Ch. 25.52 with no waiver / bonus | FAIL | Ch. 25.52; conversion must satisfy current standards |
| No sprinkler retrofit analysis | FLAG | Run Title 15 §1103.5.4 and LBMC §14.50.104/CBC §903.6(1),(5) |
| Cites Ch. 14.52.030 for sprinkler retrofit on a 3+-unit building | FAIL | Wrong citation for this occupancy — Ch. 14.52.030 reaches only one- and two-family dwellings (Ch. 14.52.026 only townhouses). Multi-family uses Title 15 §1103.5.4 plus LBMC §14.50.104/CBC §903.6. |
| Cites NFPA 13D for multi-family sprinkler design | FAIL | 13D is 1&2-family only; multi-family is NFPA 13R per CBC §903.3.1.2 |
| Tenant noticing not yet completed | FAIL | Ch. 25.47 — tenant noticing is a statutory pre-condition |
| Subdivision map omitted | FAIL | Subdivision Map Act — condo creates new fee parcels |
