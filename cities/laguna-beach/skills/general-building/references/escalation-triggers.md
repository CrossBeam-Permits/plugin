# Escalation Triggers

The one job this skill must not get wrong: letting structural work through as a counter permit.
Read the scope the applicant wrote and decide from its words. This is reasoning over the scope,
never a keyword match — "opening" in "opening up the wall for a fixture" is not the same as
"new opening in a bearing wall", and a scope that says "repair" while describing a rebuild is a
rebuild.

---

## Hard triggers — the work goes to plan review

| Trigger | Why | Section |
|---|---|---|
| Floor area, a story, or habitable space is added | It is an addition, whatever the valuation says | — |
| A bearing wall, beam, post, header, or footing is altered, removed, or underpinned | Load path change | CRC R105.2.2 |
| A new opening is cut, or an existing opening enlarged, in any wall | Needs a header and a load path | CRC R105.2.2 |
| Means of egress changes: a required exit door, window, stair, or landing | Life safety | CRC R105.2.2 |
| Occupancy or use changes, including a garage conversion | New code requirements attach | — |
| Earth is cut, filled, or moved beyond the city's adopted threshold | Grading permit | CBC Appendix J §J103 |
| Any element retains soil | Retaining-wall review | — |
| A drawing set accompanies the application | A plan checker must walk it | — |
| Structural calculations accompany the application | The design is engineered | — |
| Damage repair reaching framing, where the extent is not defined by a stamped letter | Unknown scope | CRC R105.2.2 |

## Soft signals — look closer before clearing

- A valuation far above the described scope.
- A scope written in trades rather than work: "electrical, plumbing, mechanical" with no object.
- A "like-for-like" claim on something that is not like-for-like: a different fixture footprint,
  a wider window, a taller wall.
- A resubmittal or a correction response, which means someone already reviewed this once.
- A scope naming several unrelated pieces of work at once. Name the largest piece and route on
  that; say in the finding what the other pieces are.

## What escalation looks like in the output

One finding, not a checklist:

- Name the trigger.
- Quote the words in the scope that fired it, and where they appear.
- Say what review the work needs instead.
- Do not review the rest of the application as if the permit could issue.
