# Laguna Beach — Legalizing unpermitted work, code cases and stop-work orders (resident guide)

**Law as of:** 2026-10-10
**Authority:** LBMC 25.80.002; LBMC 14.50.034-.036 (CBC 114.4, 115.3 as amended); LBMC 25.56.002;
LBMC 25.07.008(A)(1)(a); LBMC 25.17 and Gov. Code 66332 (state skill); City FAQ, fee schedule and
Issuance Requirements Checklist (`website` references; a CrossBeam reference that is not included in this plugin).
**Use for:** "I bought a house with an unpermitted room", "Can I legalize my garage conversion?",
"I got a stop-work notice", "Code enforcement opened a case", "The records show a smaller house than
I have", "Do I need as-built plans?"

## The core rule: legalizing is the same as building it new

Unpermitted work gets no credit for already existing. To keep it, the owner gets every approval the
work would need if it were proposed today, under today's code, and pays the penalty fees. The
alternative is to remove it and restore the permitted condition, with a permit for the removal.

- The City's own words: "If the records show a smaller home than what exists on the property, the
  difference is considered unpermitted and must be legalized or removed in coordination with the
  City" (City FAQ, `../../city-website/references/faqs.md`).
- Anything built or used contrary to Title 25 is "unlawful and a public nuisance", and each day is a
  separate misdemeanor (25.80.002(C)-(E)). Work that violates the building code or approved plans is
  a misdemeanor and/or administrative citation (CBC 114.4 as amended, LBMC 14.50.034).

## The method

1. **Establish what is legal.** Pull the permit history: City records for the parcel
   (the record check), approved plans, and the "Property Information" tab on the City map. The legal
   baseline is what the permits show. A Real Property Report at sale summarizes the City's file
   (`../../city-website/references/submit-real-property-report.md`).
2. **Split the unpermitted work into pieces** and run `planning-approvals` on each as if proposed
   now: Zone Clearance, ADR or Design Review; a variance if it breaks a setback, height or coverage
   standard (no nonconforming status, because only work that "lawfully existed" can be nonconforming,
   25.56.002); overlays (CDP, fire, grading, historic).
3. **Coastal (CDP) consequences.**
   - The single-family CDP exemption's ADU carve-out covers converting "habitable area within the
     walls of the primary dwelling"; habitable area means space that meets the California Building
     Code for sleeping, living, cooking or dining (25.07.008(A)(1)(a)). Unpermitted space has not been
     shown to meet the CBC. City intake asks for as-built plans to decide whether a conversion is of
     existing habitable space (ADU application only) or of non-habitable space or new construction
     (CDP also required) (City Planning intake ruling, Sept. 2026). Treat never-permitted living space
     as new floor area for the CDP test unless Planning accepts it as legally established. UNSETTLED
     where Planning has not ruled; confirm at pre-application.
   - Unpermitted floor area counts toward the 10% floor-area test in the shoreline strip like any
     other addition (25.07.008(A)(1)(c)1).
4. **Major remodel count.** The baseline is the structure that "legally existed on the site on
   January 13, 1993"; later unpermitted additions are not part of the baseline and count as additions
   (`../../residential-remodel/references/city-major-remodel-methodology.md`). Legalizing a large
   unpermitted addition can make the project a major remodel (Design Review, new-building standards,
   25.56.011).
5. **Unpermitted ADU or JADU.** State law: a city may not deny a permit for an unpermitted ADU built
   before January 1, 2020 because of a building or zoning violation, unless the building is
   substandard (Gov. Code 66332; `../../adu/SKILL.md`, reference `compliance-unpermitted`). The LBMC
   text still says January 1, 2018 (25.17); the state date controls.
6. **Building permit.** File as-built plans showing existing and demolished walls and the work to be
   legalized (the City's application drawing rules ask for as-built and proposed floor plans and
   elevations). Building decides how concealed work is verified (opening walls, special inspection,
   engineer's letter); that procedure is not in our sources, so say "Building will tell you what to
   expose". Any unpermitted work or expired permit in City records must be cleared or included in
   the current permit before issuance (City Issuance Requirements Checklist, rows "Unpermitted work"
   and "Expired permits").
7. **Fees.** "Unpermitted work is charged double permit and plan check fees"; code enforcement and
   other investigations are billed hourly (Master Fee Schedule; `../../city-website/references/fees.md`). Amounts:
   the fee estimate.

## Code enforcement cases and stop-work orders

- Code Enforcement handles complaints and violation notices; notices can be viewed on the City's
  Laserfiche portal (`../../city-website/references/code-enforcement.md`). Report or ask about unpermitted
  construction at the Building Division (City FAQ).
- **Stop-work order:** continuing work after one is served, except work the official directs to
  remove a violation or unsafe condition, is a misdemeanor and/or administrative citation, each day a
  separate offense (CBC 115.3 as amended, LBMC 14.50.036). Stop, then apply for the permits above.
- Closing the case: the normal path is a permit that legalizes or removes the work, through final
  inspection. How the City formally closes a case is not in our sources; confirm with Code
  Enforcement.
- Appeals of a Building Official decision go to the Planning Commission sitting as the Board of
  Appeals (CBC 113.1 as amended, LBMC 14.50.030).
- Historic register structures: demolition without a permit brings a five-year building permit stay
  and up to $100,000 per violation (25.45.022; `historic-properties`).
- Tree removed without a permit: Code Enforcement handles it (`trees-views-hedges`).

## What to tell the resident

1. Legalizing needs the same approvals as new work under today's code, plus double permit and plan
   check fees; removal is the other option.
2. Start with the permit history; the legal baseline is what the permits show.
3. Name the Planning route and any variance the as-built work needs.
4. In the coastal zone, unpermitted living space is likely treated as new floor area for the CDP
   test (confirm).
5. As-built plans; Building sets how concealed work is shown.
6. Under a stop-work order, stop and file; do not keep building.
