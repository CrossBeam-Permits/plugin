# Laguna Beach — Before you file: does the packet match the route?

**Law as of:** 2026-10-13
**Use for:** a packet that is drafted or already filed. `planning-approvals` names the route; this
file checks the packet against it before the City does. Two checks: the applications in the packet
(Planning), and whether Planning has to come first (Building). A method, not a list of cases.

**Authority.** LBMC 25.05.040(B) and 25.05.045 as replaced or added by Urgency Ord. 1732 (effective
2026-07-22; extended by Ord. 1733); LBMC 25.05.045(B)(3) (zoning clearance before every building
permit); LBMC 14.84.070 and Gov. Code 65850.5 (residential rooftop solar); Building Division intake
practice (Aug.-Oct. 2026), stated here as practice, not code.

## Check 1 — Is each application the right one?

Run `planning-approvals` on the project first. Then, for each City application in the packet:

1. **Same as the route** → keep it and check its documents (the City checklists, lane planning).
2. **Different from the route, and the route is established** → the filed form is the wrong one.
   A list item is established only when a sheet or a hard parcel fact shows it:

   | List item (LBMC 25.05.040) | What shows it |
   |---|---|
   | New building, (B)(1)(b) | Project description and sheet index |
   | Over 15 ft or a second story, (B)(1)(c) | Elevations and sections (ridge height above grade) |
   | Major remodel, (B)(1)(a) | Demolition and area sheets, run through the major remodel method (`../../residential-remodel/references/city-major-remodel-methodology.md`) |
   | Grading over 20 cubic yards outside the footprint, (B)(1)(f) | Grading plan earthwork table |
   | Retaining wall over 5 ft exposed, (B)(1)(g) | Wall elevations or sections |
   | Pool or spa more than 3 ft above adjacent grade, (B)(1)(j) | Pool sections |
   | Environmentally sensitive area, (B)(1)(e) | Parcel facts, then the biologist's determination |
   | Administrative Design Review items, (B)(3)(a) | Plans, elevations, landscape and equipment schedules |

   These are examples of evidence, not the full list; any item on the three lists counts the same
   way (`design-review-lists`). Say it plainly, with the evidence: "You filed a Zone Clearance
   Application. Sheet A3.1 shows the new ridge at 22 ft above grade, which is a (B)(1)(c) item, so
   this needs the Design Review Application. Swap the form; its checklist adds these items: …"
   Then list the right application's documents.
3. **Different from the route, but nothing in the packet settles it** → do not tell the applicant
   to refile. Name the one fact that decides it (for example "the elevations do not give the ridge
   height") and say "confirm with Planning at pre-application". Never call a Design Review
   Application missing on a packet that holds a Zone Clearance Application unless a list item is
   established.
4. **No application in the packet** → name the route's application(s) as the ones to file.

Two cases where the deciding fact is easy to get wrong:

- **ADU or JADU conversion.** The existing condition decides the forms, so read the as-built floor
  plans, not the proposed room label. Converting existing habitable space: the ADU & JADU
  Application only. Converting non-habitable space (a garage, storage room or attic) or adding floor
  area: the ADU & JADU Application plus a Coastal Development Permit Application in the coastal zone
  (25.07.008(A)(1)(a); `coastal-development-permits`). With no as-built floor plans, ask for them
  once, saying what each answer means; do not guess either branch.
- **A Coastal Commission area (Three Arch Bay and the other deferred-certification areas).** The
  Coastal Commission issues the CDP after City and, in Three Arch Bay, HOA clearance. Do not add the
  City's CDP Application for that permit (`coastal-development-permits`).

## Check 2 — Filing with Building: does Planning have to come first?

Every building permit needs a zoning clearance first (25.05.045(B)(3)). So the question is never
"does Planning look", but which Planning approval the scope needs before Building takes the set:

1. **Find the scope's list** from the plan set itself: site plan, floor plans, elevations, sections,
   area tables, grading and landscape plans, demolition plan. The Building application's project
   description supports the sheets; it does not replace them. Parcel facts activate list items
   (coastal and appealable area, ESA, slope, historic, specific plan), but a parcel fact alone never
   raises the list.
   - **Design Review or Administrative Design Review** → that approval must be in effect before the
     Building filing.
   - **Zone Clearance** → Planning's touch is the Zone Clearance. The usual order is the counter
     routine: the Zone Clearance is stamped first, then Building takes the set.
   - **Residential rooftop solar** on an existing house or duplex (panels and the equipment that
     serves them: racking, conduit, inverters, batteries, panels and disconnects) goes straight to
     Building (14.84.070; Gov. Code 65850.5). Other work in the same packet is judged on its own:
     a reroof under the panels is exterior work that Planning reviews; a ground-mounted array or a
     generator runs the lists.
   - The Building Division's working practice (Aug. 2026): exterior work, new construction,
     commercial work and signs go to Planning first. When that practice and the lists point
     different ways for a scope, say both and ask the applicant to confirm with Planning.
   - The sheets do not show the deciding fact (whether a wall moves, whether the ridge rises, how
     many cubic yards move, whether the work touches the exterior) → say which fact is missing.
     Never pick a list to have an answer.
2. **Is the approval already in place?** Ask for the Planning approval letter or resolution, or the
   Planning-stamped plans. A Design Review approval takes effect 14 calendar days after the decision
   unless appealed, and no building permit application may be filed in that window
   (`process-timeline-appeals`). An approval for different work on the same parcel does not count.
   An approval that has not lapsed covers its work: do not tell the applicant to refile it.
3. **Filing Planning and Building together.** Building returns a set that reaches the counter
   before its required Planning approval. Filing both the same week and hoping is the most common
   way to lose time. The exception is the counter routine above: an over-the-counter Zone Clearance
   stamped before the Building filing. An applicant who needs Building to start before Planning
   approves must ask in writing (a cover letter asking for concurrent processing); the plan checker
   decides, and nothing guarantees it.
4. **The Building plans must match the approved Planning plans.** A change after approval goes back
   to Planning as a change to the approval (`discretionary-permits`).

## How to write it

Lead with what to fix, in the order the City would stop the filing: wrong or missing application,
then Planning not yet in effect, then the documents and sheets for the right application. One line
each: what to add or change, the rule, and the sheet or page that shows it. Facts the packet does
not settle get one "confirm with Planning" line, not a refile.
