# Laguna Beach — Weighing City practice against the code (method)

**Law as of:** 2026-10-10
**Based on:** the Planning records (Tyler module 3) applied 2026-07-22 to 2026-10-08, the first
eleven weeks of Ord. 1732: 413 records (counter Zone Clearance, zoning plan checks, Administrative
Design Review, DRB and Planning Commission Design Review, variances, CDPs, historic and ADU records),
read with the linked Planning and Building records at the same parcels.

**What this file is.** A method for using what staff have done when the code leaves a gap. It is
practice, not law: LBMC Title 25 as amended by Ord. 1732 governs, and the Director may refer any Zone
Clearance or ADR project to a hearing (25.05.040(A)(2)(d)). The patterns those records showed are
written as rules in the file where each subject lives (table at the end). The guide does not keep a
list of records to match against: reason from the rule, never from a remembered case.

## When practice may enter an answer

1. **Run `planning-approvals` first.** Practice is for a real gap only: two list items fit, only a
   catch-all fits, or the ordinance is silent and the point is UNSETTLED.
2. **Never cite practice against clear code text.** The headline tier is the ordinance default
   (`planning-approvals` Step 7). Practice follows it as a fact that could move the piece, with what
   would decide it.
3. **Check the date.** A decision applied for before 2026-07-22 used the old default (all exterior
   work got Design Review unless excepted). It says nothing about how Ord. 1732 routes the same work.
4. **Weigh how settled it is.** A pattern staff applied consistently is practice. One or two
   decisions are a lean: say so and keep the point UNSETTLED.
5. **Close with "confirm with Planning at pre-application"**, and mention the Director's referral
   power without predicting it.

## How staff resolve an ambiguous list match

These are the reasoning steps the records show, in the order staff apply them. Each one is stated in
full, with its code basis, in `planning-approvals`; run them there.

1. **Is the work truly in kind?** Same size, location, height, type, materials and operation is
   (B)(2)(c), even for a thing another item would send to ADR or Design Review if built new. Any
   visible change makes it new work, and the item for the changed thing governs (Step 4d rule 2).
2. **Which specific item names the thing?** That item decides it over the catch-alls: equipment by
   the equipment items wherever it sits, decks by the deck items at any height, roofs by the roof
   items (Step 4d rule 3).
3. **Does the work itself create new height?** Only then does the 15-ft catch-all (B)(1)(c) apply:
   a new building, an addition or structure whose own roof is over 15 ft, a raised roof, an exterior
   elevator. Work on an existing building that stays the same height is never Design Review on
   height alone (Step 4d rule 3; Step 4f).
4. **Do two specific items on different lists both fit?** The highest list governs (Step 4d rule 4).
5. **What does the whole project carry?** Each piece keeps its own route; one Design Review
   Application carries the highest; a variance or a Planning Commission entitlement re-picks the
   hearing body for everything, including the CDP (Step 6 item 7; Step 7).
6. **Is there an ADU?** The ADU stays on its own ministerial application; every other piece routes on
   its own and can still draw ADR or Design Review (Steps 4e, 4h).
7. **Does state law take the piece off the lists?** Solar and paired storage on any building go to
   Building only (Step 4a-bis).
8. **Still no answer?** Mark it UNSETTLED, give both readings, and say which fact or ruling decides.
