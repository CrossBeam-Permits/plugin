# Laguna Beach -- Sewer Video Requirements and Submittal Rules for Kitchen/Bath Remodels

Source: Residential Kitchen Remodel Handout, Residential Bathroom Renovation Handout, Residential Room Alteration/Remodel Submittal Checklist
Authority: City of Laguna Beach Building Division
Last verified: 2026-08-14

## Sewer Video Requirements

Laguna Beach requires a sewer video inspection in the following situations:

| Trigger | Applies To | Source |
|---------|-----------|--------|
| **Any increase in plumbing fixture count** | All residential remodels | Kitchen + Bathroom Handouts |
| **Work valued over $100,000** in certain areas | Properties **north of Cardinal Drive** | Room Alteration Checklist |

### What This Means for Kitchen/Bath Remodels

- **Adding a fixture** (e.g., adding a second sink, adding a dishwasher where none existed, converting a half bath to full bath) triggers sewer video
- **Replacing fixtures in the same location** (e.g., swapping out a toilet for a new toilet) does NOT trigger sewer video
- **High-value projects**: Even without fixture count changes, projects north of Cardinal Drive exceeding $100,000 require sewer video

### Timing

The sewer video must be available at plan check submittal. It is not a deferred submittal item -- the city wants to verify sewer capacity before approving additional fixtures.

## OTC vs. Full Plan Review Thresholds

### OTC-Eligible Kitchen/Bath Remodels

Per the city reference and city handouts, the following qualify for over-the-counter same-day review:

- Kitchen remodel: **same configuration**, minor structural only
- Bathroom remodel: **same configuration**, minor structural only

"Same configuration" means fixtures remain in their existing locations. Minor structural includes headers for existing openings but NOT wall removal or layout reconfiguration.

**Minimum submittal for OTC**: Legible floor plan depicting the layout of the renovation.

### Full Plan Review Triggers

The following escalate a kitchen/bath remodel from OTC to full plan review:

| Trigger | Why |
|---------|-----|
| Reconfiguring kitchen/bath layout | Requires plumbing, structural, and potentially zoning review |
| Structural modifications (wall removal, enlarged openings) | Requires structural engineering and calculations |
| Sprinkler retrofit triggered (50% valuation threshold) | Requires sprinkler design plans |
| Major remodel triggered (50% demolition threshold) | Treated as new construction |
| Exterior changes visible from public areas | May trigger Administrative Design Review |

## Full Plan Review Submittal Checklist

When a kitchen/bath remodel requires full plan review, submit:

| Item | Details |
|------|---------|
| **Plan sets** | 2 sets of scaled 24"x36" drawings |
| **Title sheet** | Owner name, address, project address, scope of work, index sheet, vicinity map, deferred submittals list |
| **Adopted codes statement** | Reference 2025 editions of all California codes + Laguna Beach local ordinances |
| **Site plan** | Required if exterior work included; show projecting elements and distances to property lines |
| **Floor plan** | New and existing layouts showing door/window sizes, headers, outlets, switches, FAU, registers, plumbing fixtures |
| **Section cuts** | Through modification areas showing framing, relationship to existing structure |
| **Roof plan** | If applicable; Class A roofing assembly with approved evaluation report number |
| **Exterior elevations** | If applicable; finish materials, openings, heights; comply with VHFHSZ and Ch. 7A |
| **Structural plans** | Framing members, beams, lateral system, footings, details |
| **Structural calculations** | 2 sets justifying all structural elements |
| **Energy compliance forms** | 2 sets (Title 24 CF-1R, MF-1R) |
| **Sewer video** | If fixture count increases or >$100K north of Cardinal Drive |

## Window and Door Requirements

Per the Room Alteration/Remodel Checklist:

> WINDOWS & DOORS -- must be dual pane with one pane tempered.

This applies to any new or replacement windows/doors installed as part of the remodel. This is more specific than the general state code requirement and reflects Laguna Beach's VHFHSZ status.

For windows in VHFHSZ areas (Ch. 14.70):
- **Vinyl windows**: Welded corners + metal reinforcing required
- **No plastic skylights**: Glass only

## City Handout Highlights (Not in State Code)

The Laguna Beach kitchen and bathroom handouts are largely a restatement of state code requirements. The following items are the city-specific additions beyond what the state skill covers:

1. **Sewer video for fixture count increases** -- state code does not require this
2. **Sewer video for >$100K north of Cardinal Drive** -- geographic trigger unique to Laguna Beach
3. **Dual pane + one tempered window requirement** -- more specific than state language
4. **Loop vent for kitchen island sink** -- called out specifically in the kitchen handout (state code allows this but city explicitly requires it)
5. **Installation instructions required at inspection** -- CMC 303.1 is state code but city handout emphasizes field inspectors will check for manufacturer installation instructions for all listed equipment
6. **Recording test gauge alternative for gas testing** -- kitchen handout notes that a lower gas pressure test may be performed when using a recording test gauge (CPC 1213.3)
