# Fee calculator

_Generated by the plugin publisher from the maintained Laguna Beach fee schedule. Do not edit by hand; changes are overwritten._

**ESTIMATE ONLY. The City of Laguna Beach has not confirmed these amounts or the Building permit fee formula. The City sets the final fee when it invoices the permit.**

`fee-calc.mjs` is the shared fee calculator, copied unchanged. `../estimate-fees.mjs` runs it over `../../requirements/fees/fee-schedule.json`. Node 18 or later; no packages to install.

```
node scripts/estimate-fees.mjs --input project.json
node scripts/estimate-fees.mjs --input '{"permitType":"adu","valuation":180000,"aduSqft":600}'
node scripts/estimate-fees.mjs --list
```

Add `--json out.json` to also write the full breakdown. The agent decides the inputs from the project documents. The command only does the arithmetic. Leave a value out when the documents do not give it; never guess one.

## Input fields (calcFees)

| Field | Meaning |
|---|---|
| `permitType` | Required. One of the permit types `--list` prints (for example `adu`, `addition`, `remodel`, `reroof`). |
| `valuation` | Project valuation in dollars. For a new-floor-area scope the calculator uses the higher of this and the ICC minimum. |
| `newFloorAreaSqft` | New floor area in sq ft. |
| `aduSqft` | ADU floor area in sq ft. One ADU per run. |
| `primaryDwellingSqft` | Primary dwelling floor area, for fees charged in proportion to it. |
| `newDwellingUnits` | Number of new dwelling units. |
| `occupancy` | `R-3` (default), `R-2`, `U` or `B`, for the ICC valuation. |
| `isCombinationPermit` | `true` for a new-construction combination trade permit. |
| `permitCount` | Number of permits issued. |
| `structureUse` | `residential` or `nonresidential`. The state strong-motion fee needs it. |
| `stories` | Story count. The state strong-motion fee needs it for a residential building. |
| `scopes` | Extra fee scopes the project triggers (for example `geotechnical_peer_review`). `--list` prints them. |
| `scopeQuantities` | Counts for unit fee rows, as `{ "id": number }`. `--list` prints the ids. |
| `conditions` | Location facts that are true, for example `utility:laguna_main_sewer`. |
| `resolvedConditionGroups` | Condition groups that were checked. A checked group without its condition means the fee does not apply. Unchecked groups stay "needs details". |
| `existingHabitableConversion` | `true` when the work converts existing habitable space. |
| `planningFeeIds` | Not a calculator field. Planning fee ids to list as published (`--list`). |

The schedule has 83 unit-row ids for `scopeQuantities`.
