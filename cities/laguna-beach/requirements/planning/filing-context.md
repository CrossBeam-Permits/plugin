# Existing applications and public-owner authorization

_Generated by the plugin publisher from the maintained Laguna Beach requirements source. Do not edit by hand; changes are overwritten._

This is evidence-handling guidance, not a City waiver. It does not change the entitlement the project requires. Read the operative submittal and City receipt, prior acceptance, reviewer direction and any prior application of record. A form's publication date is not its submission date. An old edition alone neither proves acceptance nor proves the applicant owes a replacement. For a clearly new application use the current published requirements. Continue evaluating the known entitlement's supporting checklist while that question is unresolved. A new entitlement not covered by that prior filing is a separate application, provided its need is established. For a City or Caltrans right-of-way site, identify the public owner and inspect the authorization or agreement actually supplied. Do not presume a private-landowner signature is the only acceptable instrument; equally, public ownership does not establish a waiver. Do not request a private title report merely because a survey of a public street was submitted. Keep each source's owner affidavit, drawing disclosure and right-of-way access requirement distinct. One artifact can satisfy several requirements only when its contents do so. When the semantic filing classification establishes an extension-of-time request, these five rows are not applicable: geotechnical study, coastal hazards study, advance deposit agreement, title report, and digital site photos. The filing extends an existing approval; it does not require replacement studies or owner documents merely because the ordinary application checklist lists them. Judge every other row on any scope change the request carries, as for any filing. A physical addition or deck extension alone is not an extension of time. Fire access and hydraulic applicability follow their own scope rules, not this five-row exclusion. Record the prior approval and the request evidence; never infer this class from the permit prefix or a filename.
