# Laguna Beach Building: how to resubmit

_Generated by the plugin publisher from the maintained Laguna Beach requirements source. Do not edit by hand; changes are overwritten._

Source: City of Laguna Beach Building Division staff guidance (August 2026). Reported by City staff; confirm with the Building Division.

## Resubmit into the original document slot

The City names this as its top resubmittal failure.

> A common resubmittal mistake includes resubmitting files as new standalone documents instead of uploading them into the required document section.
>
> - This messes up the versioning in the system for review
> - The system will not allow they to resubmit their project because it thinks required items are outstanding

Concretely: use the **Resubmit** button on the existing document, so the new file lands as a new version of that document. Uploading it as a fresh standalone document breaks EnerGov versioning, and the portal then blocks the resubmittal because it still counts the original item as outstanding.

## File-name round markers

> All original files have "PC 1 - ORIGINAL SUBMITTAL" in the name All resubmitted files have "PC 2 – RESUBMITTAL" in the name

**The City applies this renaming, not the applicant.**

## The plan-check response document

> Plan check responses are not usually included for a completeness check but sometimes they are
>
> - This document should be a list of corrections made and where to find them

And: **each resubmittal requires its own separate response sheet.**

So:

- Its absence at a completeness check is normal City practice and must not make a packet incomplete.
- **When present, it has a shape.** A corrections-made list keyed to where each change lives in the set.
- **One sheet per resubmittal.** A response covering several rounds does not satisfy the current round. Round 3 needs its own response sheet, not an amended round-2 sheet.
