# Laguna Beach Building: one plan set, separate applications

_Generated by the plugin publisher from the maintained Laguna Beach requirements source. Do not edit by hand; changes are overwritten._

Source: City of Laguna Beach Building Division staff guidance (August and September 2026) and City review letters. Reported by City staff; confirm with the Building Division.

## One plan set for the whole project

**The City wants exactly one complete plan set covering the entire project, and breaks the individual permits off that shared set.**

> In this case they separated out the plans, (1) for the house and (1) for the (ADU). We only want (1) complete set of plans for the entire project and we will break out multiple permits off of this same shared set of plans.

**Multiple separate plan sets is a City correction, not a valid structure.**

The split the City wants is on the **applications**, never on the plan set.

The applications-to-plan-set relationship, therefore:

- **Applications split by scope.** One per scope, each with its own description and its own valuation.
- **Plan set does not split.** One complete set, all scopes drawn in it.
- **Tracking does not split.** *"Plans that will have separate permits issued off of the same plan check are tracked and reviewed under the main record. Fees and permits are captured/issued per individual permit (even if off the same set of plans)."*

## Application pages may be combined into one PDF

**Separate application files and one combined application PDF are both acceptable**, so long as every page is present.

> While applications were uploaded as separate files, all of these pages can be combined into (1) pdf and uploaded together so long as they are all accounted for.

One PDF, four PDFs, or a set filed under the wrong-looking category are all fine. What matters is that every application page is present and every scope has one.

## Energy calculations

**The 8.5 × 11 calculation packet may be uploaded separately. The full-size energy sheets belong inside the plan set.**

> Energy calculations can be submitted separately but usually include a set of 8.5" × 11" pages; full sized sheets should be included in the plans

The distinction is sheet size and role, not file separation. A standalone 8.5 × 11 Title 24 compliance report is a normal, expected separate document. Full-size plan sheets carrying the energy details are plan sheets and belong in the one plan set.

## Grading

**20 cubic yards outside the building footprint is the line.** Count only grading outside the footprint, using the greater of cut or fill. Grading inside the footprint never counts.

- **≤ 20 CY outside the footprint** — the grading rides the application it applies to. No separate application. The City's round-1 letter asks applicants to state *"grading quantities in cubic yards (CY) if under 20 CY"* in each scope's description, so the quantity is declared even though it needs no application of its own.
- **> 20 CY outside the footprint** — its own application, its own valuation, and its own permit. Off the **same plan set**, like every other scope. The City's example description: *"500 CY of grading for new SFR"*.

*"grading under 20 CY is added to the application it applies to. If grading is over 20 CY, it requires its own application (with valuation) and permit (same plan set)."*

This restates the E-Plan guide's listed scope (4) with the City's 8/19 confirmation that the plan set stays single.

## Permit splits the counter applies

These are permit/application splits, never plan-set splits:

- **BIPV solar roof.** One shared set produces two cross-referenced permits: one for the photovoltaic roof tiles and one for the non-generating metal roof tiles.
- **ADU and JADU.** The counter normally opens one permit per unit even when the units are drawn inside a larger project. One set showing a main house, JADU and ADU therefore produces two applications: main house + JADU, and ADU. A house with an ADU may go through one plan check, but the City issues two permits, one per address, each with its own permit and plan-check fee.
- **Demolition.** Demolishing a dwelling unit requires a separate demolition permit. A demo-only permit is normally not issued unless a formal replacement-construction submittal is on file or the Building Official approves it.
- **Grading.** Use the greater of cut or fill outside the building footprint for the 20-CY permit test. More than 20 CY gets its own grading application, valuation, permit and plan submittal. 20 CY or less rides on the applicable construction permit. Grading wholly inside the footprint still receives grading review and a fee; it never counts toward the 20 CY and never needs its own application.
- **Pool or spa with a new house.** The E-Plan guide already makes the pool/spa its own application with its own valuation.

The reason for every split is traceability: each EnerGov record has one scope, description, valuation and fee set while the technical reviewers work from one coordinated drawing set.

## MEP applications

A separate MEP application per scope, not one for the project.

The MEP *application* is an intake matter; MEP *counts* are not.

## Duplicate and extra documents

*"Sometimes people include other documents (some of those documents might even be duplicate files)."* Extra documents are not a defect.
