# Laguna Beach plan-set standards

_Generated by the plugin publisher from the maintained Laguna Beach requirements source. Do not edit by hand; changes are overwritten._

Source: The City documents named in each section: the Digital Plan Submittal Guide (E-Plan), the Building Plan Check Submittal Requirements for New Construction, Additions & Major Remodels (2025), Building Plan Review Services (06/08/2026), the Residential Submittal Checklist for Room Alterations/Remodels (document 5129), the Residential Review Worksheet (7-14-25) and the Zone Clearance Application (July 2026)

How a plan set drawn for a Laguna Beach project meets the City's Building and Planning sheet lists, so it passes intake by construction rather than by correction. Which sheets each project type needs is in `plan-sheet-matrix.md`.

## How to use these standards

1. Settle the scope first. Which project type a scope is, which Planning review level applies, and which Building case it is are judgments made from the plans, the site facts and LBMC §25.05.040(B).
2. Laguna sequences the lanes. Planning approval comes before the Building submittal, and the Building plan set must match the plans Planning approved. Draw the Planning sheets first. The Building set grows from the same sheets. A change after Planning approval goes back to Planning before Building accepts it.
3. or with a stated trigger applies only when its trigger is established. Where the trigger is unknown, carry the sheet as an open item; do not draw it by default and do not drop it silently.
4. "Staff may request additional items after review of an initial submittal." The matrix is the intake floor (City note printed with the matrix).

## 2. Building sheets per case

The Building set is one plan set for the whole project. The City breaks the separate permits off that one set.

## 4. Title block, north arrow, legend and scale

**Title block.** No Laguna source prescribes a title-block layout. The cover or first sheet must carry the project address and the complete scope of work. Put the address, the property owner, the preparer, the sheet number and title, the scale and the date in every title block so each sheet routes to this job on its own.

**North arrow.** Planning asks for a north arrow showing magnetic and project north on the site plan and the floor plans, a north arrow on the staking plan, and floor plans oriented to match the site plan. Draw a project-north arrow and a magnetic-north arrow. The magnetic-north angle is a measured or documented value with a source; an unmeasured angle prints with its field-verify tag, and a missing one prints as an open item.

**Legend.** Planning asks for a legend on the site plan (line types, hatched or shaded areas, abbreviations). On the as-built floor plan it asks for a legend that identifies existing walls to remain (plain), existing walls to be rebuilt (shaded), walls to be demolished (dashed) and proposed new walls (dark shade), with a table that tallies existing and demolished wall lengths in linear feet. Elevations need a legend for the shading or crosshatch that marks new work and demolition. Building asks the floor plans to tell apart walls to remain, walls to be demolished and new walls, and counts an existing wall with a structural upgrade to the foundation or lateral system as new.

**Scale.** Every Planning sheet indicates its scale. The Zone Clearance Application sets these scales:

| Sheet | Scale |
|---|---|
| Survey, site plan, roof plan, landscape plan, lighting plan, site and right-of-way improvement plan | 1/8" = 1'-0" |
| Floor plans, elevations, cross sections, floor area calculations, open space calculations | 1/4" = 1'-0" |

These scales are required for a Zone Clearance submittal. The Residential Review Worksheet used for other Planning applications asks only that each sheet indicate its scale. Whatever the scale, the view prints at the scale it states.

**Heights and grades.** On elevations: label height elevations of roofs, floors, plate lines, decks and railings; show existing grade dashed and proposed grade solid; show the maximum allowed building envelope dashed (LBMC 25.50.004(d)). Floor area calculations are a separate dimensioned diagram built from geometric shapes, measured from the outside structural wall, with a table that tallies each area.

## 5. Files and sheet size

- **One PDF plan set.** Combine all plan sheets into one PDF plan set. Plan sizes 8.5 x 11, 11 x 17 or 24 x 36. Build at 24 x 36 (ARCH D) unless the project is minor and every sheet stays legible smaller.
- **Online: keep letter-size documents out of the plan file.** For an online filing, upload structural calculations, letters, reports and product sheets as their own files, not inside the plan file. The Building Division returns a plan file that mixes letter-size documents with plan sheets (Building return note, September 2026: "all plan sheets must be 11" x 17", with structural calculations and other 8.5" x 11" documents uploaded separately"). The City has accepted plan files whose drawing sheets came in more than one large size; whether a mix of large sizes is returned is unsettled, so confirm it with the Building Division rather than calling it a fix.
- **Energy.** Full-size energy sheets go inside the plan set. The 8.5 x 11 Title 24 report may be uploaded as its own file.
- **Applications.** The application pages may be one PDF or several, as long as every page is there. The City's application is filled by the filer, not drawn.
- **Portal upload slots.** On the online portal, every required slot takes PDF only and exactly one file: one "Plans" file and one application file ("Application" on Planning records, "Permit Application" on Building records). Optional slots such as Reports or Energy Calculations take several files. So the plan set must be one merged PDF, and a multi-page application is merged into one PDF before upload.
- **Unlocked and legible.** Upload files without passwords or security restrictions. Plans that are not legible may be rejected before plan review.
- **Description.** The scope of work on the plans reads the same as the scope on each application.

## 6. Resubmittals

- Resubmit each revised file into the original document slot in the portal, as a new version of that document. A new standalone upload breaks the record's versioning and the portal then blocks the resubmittal.
- The City renames files with round markers ("PC 1 - ORIGINAL SUBMITTAL", "PC 2 – RESUBMITTAL"). The applicant does not.
- A plan-check response is a list of the corrections made and where to find them. Each resubmittal has its own response sheet. The City says one is not usually included for a completeness check, but sometimes is.
- No Laguna source states a clouding rule. Cloud and tag each change anyway, so the response sheet can point at it.
