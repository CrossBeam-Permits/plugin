# Profile: lot split or small multi-unit

Permit type ids to try: `multi-unit-residential`, `adu` (for an SB 9 unit), `single-family-residential`.

## Intake
- Units, sizes, stories, parking; whether the lot is split (urban lot split, subdivision, condo map) and who will own what.
- Existing units and tenants (occupied now or in the last several years); whether any are rent-controlled or deed-restricted.
- Whether the owner will live on the property (some lot-split laws require an affidavit).

## Questions
| Topic | Where to look |
|---|---|
| Which state path applies (SB 9 unit or lot split, density bonus, by-right housing streamlining) and its eligibility tests | State statutes; site facts for hazard, historic and farmland exclusions |
| Objective standards the City may apply, and which it may not | State statute; city objective-standards ordinance |
| Density, setbacks, height, coverage, open space, unit size | City zone chapter; state statute |
| Tenant protection, demolition and replacement-unit rules | State housing law; city code |
| Parking, and transit exemptions | City parking chapter; state statute; site-facts transit |
| Subdivision or map requirements, frontage, easements, utilities per lot | City subdivision chapter; state Subdivision Map Act |
| Inclusionary or affordability requirements; impact fees | City inclusionary ordinance; `crossbeam_fees` |
| Review path, hearings and the decision clock | State statute; city procedures |

## Extra checks
- `crossbeam_hcd_letters` with the city and `rule_pattern` (e.g. "SB9", "objective standards"): local rules HCD has struck.
- `crossbeam_permit_status` with the address.

## Cards
Which state path applies · units and density (fit table) · objective standards · tenants and replacement units · parking · the lot split or map · affordability and fees · review path and timeline.

## Intake checklist additions
Tentative or parcel map; title report; tenant history declaration; owner-occupancy affidavit if required; utility plan per unit or lot; architectural and civil sets.
