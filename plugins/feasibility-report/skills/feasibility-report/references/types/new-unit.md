# Profile: new unit (ADU, JADU, conversion)

Permit type ids to try: `adu`.

## Intake
- Unit type: detached, attached, conversion of existing space (garage, accessory building, part of the house), JADU.
- Size, bedrooms, baths, stories; whether the main house has fire sprinklers; existing units on the lot.
- Distance to the main house and other buildings; utilities to extend (sewer lateral, water, electric service size).
- Whether the City's pre-approved plans are an option for the owner's wish list.

## Questions
| Topic | Where to look |
|---|---|
| Size cap and minimum, by unit type and bedrooms | City ADU section; state ADU statute |
| Height, setbacks, lot coverage, FAR, open space, and what state law waives | City ADU section and zone standards; state ADU statute |
| Separation from other buildings (zoning, then building code fire separation) | City code; residential code |
| Parking and the transit exemption | City ADU section; state ADU statute; site-facts transit distance |
| Fire sprinklers | State ADU statute; city and fire code amendments |
| Owner occupancy, rentals, sale, number of units on the lot | City ADU section; state ADU statute |
| Impact and connection fees and their size thresholds | State ADU statute; city fee schedule |
| Review path and decision clock; pre-approved plans | City ADU section; state ADU statute; City page |
| Law that starts later for ADUs | `../04-state-law.md` section 3 |

## Extra checks
- `crossbeam_hcd_letters` with the city (California): ADU rules HCD has told this city to fix.
- `crossbeam_permit_status` with the address: an open permit or a live approval there.

## Cards
Size and bedrooms · height, setbacks and coverage · separation · parking · fire sprinklers · fees · extra reports (survey, soils, title, energy, solar) · easements · owner occupancy, rentals and unit count.

## Intake checklist additions
City ADU application form; site plan with setbacks, separation, coverage table and transit walking distance; floor plan with floor-area calc; energy report; electrical load calc; sewer and water routing; school district fee form.
