# Response sheet

Use this for each city resubmittal. Follow the city's own format if the city gives one. The city's format wins.

Rules:

- One numbered response per city comment, in the city's order and numbering.
- Quote the comment exactly.
- State only what changed. Claim nothing beyond the changes.
- Name each sheet and the delta tag of each clouded change.
- Check every sentence against `project.json` and the sheets before the owner signs.

```text
RESPONSE TO PLAN CHECK COMMENTS

Permit / record number: <number>
Project address:        <address>
Plan check round:       <n, as the city numbers it>        Date of comments: <date>
Plan checker:           <name or agency, as the city's letter states>
Resubmittal date:       <date>
Prepared by:            <owner name> (<owner-builder / owner / builder>)

COMMENT <n>
Comment:  "<exact text of the city's comment>"
Response: <What changed, in one to three sentences. Use the words on the sheet.>
Sheets:   <sheet IDs>        Revision: Δ<rev>, clouded

COMMENT <n+1>
Comment:  "<exact text>"
Response: <...>
Sheets:   <...>              Revision: Δ<rev>, clouded

FILES IN THIS RESUBMITTAL
<n>. <file name> — <contents>
...

<Include the next sentence only if the page-by-page comparison proved it:>
No changes were made other than those clouded and listed above.

<Owner signature line, if the city asks for one. The owner signs.>
```

If a comment asked for something the owner did not do, write the reason and the citation in the response. Do not leave the comment out.
